## Library conflict with tailwind and boostrap. 

**Problem:** Importing both `@import "tailwindcss"` and `import 'bootstrap/dist/css/bootstrap.min.css'` caused a stylesheet conflict — duplicated resets and overlapping classes meant the later import overrode the other's base styles.

**Resolution:** Removed the Bootstrap CSS import and standardized on Tailwind CSS. Only Tailwind's Preflight reset is active now.

**Prevention:** Do not import a second full CSS framework. If Bootstrap components are needed, import only their specific styles.
